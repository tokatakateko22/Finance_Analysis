# Tools & libraries

| Tool | Why |
|------|-----|
| **Pandas** | Primary wrangling, joins, group-bys — matches assessment emphasis on Pandas fluency |
| **SQLite** (`sqlite3` + `DataFrame.to_sql` / `read_sql`) | Show SQL fluency for portfolio rollups without standing up a server |
| **matplotlib / seaborn** | Simple, reproducible static charts for the stakeholder pack |
| **Jupyter** | Narrative + code + charts in one reproducible artifact |
| **Path / typed loaders** (`src/load_data.py`) | Consistent date parsing and nullable FK handling across notebook and batch run |

Not used (explicitly out of scope for this assessment): LLMs, APIs, web UI, production databases.
